# Проверка 0.3.0-preview.2

7 октября 2026 года. Изменены стартовый интерфейс, определение GPU для мониторинга
и выбор комплектного worker при переносе portable-сборки. Алгоритмы обучения и
игровой мод не изменялись. Полноценная тактическая модель пока не готова.

Причина дубля GPU: виртуальный дисплей сообщал то же имя, что физическая NVIDIA,
а неизвестные LUID из счётчиков создавали дополнительные безымянные пункты.
Добавлена проверка D3DKMT_ADAPTERTYPE: виртуальные дисплеи и программный рендерер
исключены. Имена не используются как уникальные идентификаторы оборудования.

Проверено на Windows x64 с одной RTX 5090:

- 12 проверок мониторинга: реальная CPU/RAM-нагрузка, корректное завершение,
  отдельные GPU, неизвестные счётчики, типы устройств. Живой список содержит
  одну физическую RTX 5090 с действующими показаниями GPU/VRAM.
- 28 проверок интерфейса: успешная настоящая проверка Python/библиотек,
  отзывчивость UI, модальное окно RU/EN, видимость действий при отсутствии
  Python, настройки, продолжение без обучения, выход во время проверки,
  порядок показа истории изменений и запрет обновления во время задания.
- Переезд portable-сборки переключает комплектный worker; отдельный явно
  выбранный модуль разработчика сохраняется.
- Изображения окон просмотрены. Обе DOCX-инструкции пересобраны, проверены,
  отрисованы Microsoft Word без изменения исходных DOCX; по девять страниц.

Недоступные аппаратные показания остаются неизвестными, а не выдуманным нулём.
Две настоящие одинаковые видеокарты проверены синтетическим набором, а не
двухкарточной машиной. Аппаратная проверка AMD/Intel остаётся отдельной задачей.

Определение типов сверено с Windows SDK `d3dkmthk.h` и
[описанием D3DKMT_ADAPTERTYPE](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/d3dkmthk/ns-d3dkmthk-_d3dkmt_adaptertype).
