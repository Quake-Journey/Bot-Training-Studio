# Проверка 0.1 — 7 октября 2026

Объём проверки: самостоятельное приложение, процессный протокол и начальный
обучающий модуль. Исходники и сборки игрового мода не изменялись.

- Сборка .NET: без предупреждений/ошибок.
- 17 проверок Python: целостность данных, отсутствие пересечения выборок,
  повтор старых наблюдений, нечёткие ники, обучение, совместимость весов,
  отмена во время обучения и экспорта, сохранность активного поколения.
- Межпроцессная проверка desktop → Python: определение оборудования,
  настоящий шаг обучения CPU, обработка ошибки, обучение на наблюдениях
  q2duel5 и отмена следующего задания. 34 последовательных события;
  при отмене прежний указатель поколения не изменился.
- 24 представления GUI: 6 страниц × 2 языка × 2 темы; отдельно просмотрены
  русская тёмная главная страница и английская светлая страница обучения.
  Системная тема следует настройкам ОС; отдельные снимки для неё не делались.
- Сборка опубликованной локальной папки проверена отдельно: GUI и CPU-worker
  запускаются из неё. Диагностический C-экспорт компактной модели побитно
  совпадает с Python на 12 338 строках, включая границы ветвления;
  NaN и null отклоняются. Это проверка формата, не игровой механики.

## Кандидаты моделей: вычислительная проба

Windows x64, RTX 5090 (32 ГБ), PyTorch 2.10.0+cu128. Для каждой модели:
2 синтетических примера с полной для профиля историей, forward/backward/Adam,
подтверждено изменение весов. Память ниже — пик тензоров, не весь расход GPU.

| Профиль | Параметров | История | Пик тензоров, МиБ |
|---|---:|---:|---:|
| Compact | 402 691 | 16 | 23,9 |
| Balanced | 3 175 427 | 32 | 67,7 |
| Large | 18 963 459 | 64 | 320,5 |
| XL | 56 825 859 | 128 | 905,0 |

CPU: Compact также прошёл forward/backward/обновление весов. AMD/Intel
оборудование не проверялось. Результат на 5090 не сертифицирует 4090.
Эти пробы не доказывают эффективность использования всех 24/32 ГБ:
большие последовательные датасеты и подбор нагрузки ещё впереди.

## Настоящее обучение на наблюдениях q2duel5

Одинаковый подготовленный набор: 12 000 наблюдений в каждой из обучающей,
валидационной и тестовой выборок, связанные записи сгруппированы по матчам.
20 эпох; текущая наблюдаемая история — один вектор. Метрика RMSE в единицах
Quake/с, цель — будущая скорость через 300 мс.

| Модель | Валидационная RMSE | Продолжение текущей скорости | Обучение и экспорт, с |
|---|---:|---:|---:|
| Reference | 133,90 | 168,62 | 2,61 |
| Compact | 130,77 | 168,62 | 5,05 |

Оба результата прошли текущий экспериментальный порог. Это не измерение
фрагов, качества тактики или управления персонажем. Тестовая выборка не
используется для выбора эпохи; сравнение архитектур требует дальнейшего
независимого набора, а не многократного подбора по одной проверке.

Сырьевые демки, личные ники и локальные пути не опубликованы. Синтетические
регрессионные проверки воспроизводятся из исходников; полное воспроизведение
чисел этой таблицы требует соответствующих локальных данных.

## Не проверено / не реализовано

Нет прямого GUI-импорта DM2/MVD2/BSP, тактической модели, нативной проверки
игры, загрузчика пакетов в моде и пользовательского установщика ML-среды.
Нет сертификации игрового качества, обучения на всех GPU или автоматического
восстановления после OOM. Публичный материал — исходники этапа разработки.
