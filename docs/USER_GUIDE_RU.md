# Bot Training Studio by ly

Руководство пользователя • Русский • Версия 0.2, предварительная сборка

Обновлено: 7 октября 2026 года

## 1. Назначение и текущие возможности

Bot Training Studio — самостоятельная программа для локального изучения игровых записей и обучения моделей для ботов OpenTDM-X. Модель работает на компьютере пользователя, на GPU или CPU. Демки и карты не отправляются в облако.

В этой предварительной версии работают проекты карт, импорт BSP и записей DM2/MVD2, анализ маршрутов и наблюдаемого стиля, подготовка выборок, обучение, дообучение с повтором прежнего опыта и сохранение контрольных точек. Интерфейс и вычисления работают независимо.

**Полноценная тактическая модель ещё не готова.** Хорошее предсказание действий из демки не доказывает, что бот хорошо сыграет матч. Выбор оружия, контроль предметов, полное выполнение триксов и тактика требуют дальнейшей проверки. Создаваемые пакеты пока предназначены для офлайн-проверки в студии: устанавливать их в текущую game DLL мода нельзя.

Будущий игровой мод будет читать проверенные данные, а не запускать нейросеть на сервере. Для этого потребуется официальное обновление загрузчика мода; пользователям не потребуется самостоятельно компилировать DLL.

### Быстрый порядок работы

1. Распакуй полную сборку и запусти **BotTrainingStudio.exe**.
2. В «Настройки» выбери язык и тему. В «Модели и GPU» проверь оборудование.
3. В «Карта и демки» укажи BSP, игровые записи, отдельные записи триксов и папку проекта.
4. Выполни импорт, затем анализ маршрутов и стиля.
5. В «Обучение» добавь проекты, подготовь выборку и выбери отдельную папку модели.
6. Подбери размер пакета, запусти обучение и изучи результаты на независимых матчах.
7. Сохрани прошлое поколение. Пакет из «Библиотека» используй пока только для офлайн-проверки.

## 2. Установка и настройка интерфейса

Текущая настольная сборка предназначена для Windows x64. Нужен полный каталог приложения, а не один EXE: рядом находятся папки **runtime**, **worker** и **docs**. Комплектная среда Python определяется автоматически. Для RAR дополнительно нужен установленный WinRAR/UnRAR; DM2, MVD2 и ZIP обрабатываются без него.

Проверены CPU и NVIDIA CUDA. В коде предусмотрены ROCm и Intel XPU, но поддержка конкретных AMD/Intel GPU ещё не подтверждена аппаратными проверками. GPU-профили не имеют общего ограничения в 4 ГБ видеопамяти. Больший профиль требует больше ресурсов и сам по себе не гарантирует лучшее качество.

### Язык: Настройки → Язык

| Выбор | Поведение |
| --- | --- |
| Как в системе | По умолчанию. Русский при русском языке интерфейса системы; английский во всех остальных случаях. |
| Русский | Русский интерфейс независимо от языка системы. |
| English | Английский интерфейс независимо от языка системы. |

Изменение применяется сразу и сохраняется между запусками. Учитывается язык интерфейса пользователя Windows, а не региональный формат чисел. Ранее сохранённый явный выбор сохраняется; чтобы вернуться к автоматическому режиму, выбери «Как в системе».

Тема выбирается там же: **dark** — тёмная, **light** — светлая, **system** — системная. Технические ключи журналов и сообщения сторонней среды могут оставаться на английском. Изменение языка не переводит уже записанный журнал заново.

### Разделы программы

| Раздел | Для чего нужен |
| --- | --- |
| Главная | Готовность среды и переход к обучению. |
| Карта и демки | BSP, записи, импорт, маршруты, стиль и проверка движений. |
| Обучение | Подготовка выборок, обучение, дообучение и возобновление. |
| Модели и GPU | Обнаружение устройств, профили и проверка вычислений. |
| Библиотека | Создание и проверка офлайн-пакетов. |
| Задания | Прогресс, журнал, отмена и результаты. |
| Настройки | Язык, тема и пути среды обучения. |

## 3. Карта, демки и проект

Для каждого проекта выбирается BSP одной карты. В поле игровых записей указываются DM2, MVD2, ZIP или RAR, по одному пути в строке. Отдельные демонстрации движений добавляются в поле записей триксов. Сохраняй оригиналы: для обновления анализатора может понадобиться повторный импорт.

**Проверить список** показывает найденные записи. **Импорт / дополнение** добавляет материал к проекту и использует проверенный кэш неизменившихся записей. **Новая выборка** формирует свежую выбранную подборку; это действие не заменяет обучение новой модели. Старые ревизии проекта сохраняются. Для полностью независимого эксперимента выбирай новую папку проекта.

Импорт проверяет карту, записи и происхождение данных. Изменения декодера или формата наблюдений могут потребовать повторного декодирования. Если нужный исходник отсутствует, восстанови его и повтори действие. Ошибка или отмена не должны заменять действующую ревизию неполным результатом.

После импорта используй **Изучить маршруты и стиль**. Команда **Проверить движения через физику** проверяет восстановленные фрагменты движения. Успешный короткий фрагмент не означает, что целый сложный трикс уже выучен и надёжно выполняется.

### Донор стиля

Поле «Донор стиля» ограничивает анализ выбранным игроком; пустое поле означает всех подходящих игроков. Используются нормализация оформления ника и поиск похожих имён. Проверяй найденную личность по результатам: сходство ника не гарантирует совпадение человека.

Текущий анализ описывает наблюдаемые привычки: движение, оружие и поведение в разных условиях. Это ещё не полный игровой клон. Фразы должны относиться к выбранному донору. Включение чата в пакет — отдельный выбор, по умолчанию выключенный.

### Качество исходного материала

- Используй несколько независимых матчей, разных соперников и ситуаций.
- Не выдавай две записи одной встречи за независимые примеры.
- DM2 не содержит всех скрытых состояний и исходных команд игрока.
- Предмет в сетевом кадре не обязательно виден игроку; отсутствие предмета в кадре не доказывает отсутствие на карте.
- Малая или однообразная выборка не позволяет достоверно оценить тактику.

## 4. Подготовка и обучение моделей

В «Обучение» перечисли папки проектов, по одной в строке. Кнопка «Добавить текущую карту» добавляет проект из раздела импорта. Выбери длину истории наблюдений и максимальное число примеров в каждой части выборки. Длинная история требует больше памяти; она должна помещаться в контекст выбранного профиля.

**Подготовить данные проектов** создаёт набор для модели последовательностей. Матчи разделяются на обучение, выбор поколения и итоговую проверку целыми связанными группами. Проверочные записи не должны попадать в обучение. Если независимых групп недостаточно, добавь демки, а не смешивай части выборки.

### Профиль и устройство

| Параметр | Назначение |
| --- | --- |
| auto | Выбор доступного ускорителя с предусмотренным переходом на CPU при нехватке памяти в обучении. |
| cpu / cuda | Явный выбор CPU или NVIDIA CUDA. |
| rocm / xpu | Экспериментальные пути AMD/Intel; требуют совместимой среды и отдельной проверки. |
| Compact / Balanced / Large / XL | Растущая ёмкость экспериментальной модели. Выбор проверяется измерением ресурсов. |

Кнопка **Подобрать размер пакета по памяти и скорости** измеряет настоящий вычислительный шаг выбранной модели. Результат действует для соответствующего семейства модели. Это не измерение качества игры. При нехватке памяти уменьши пакет, контекст или профиль; явный выбор GPU не означает автоматического перехода на CPU.

### Режимы работы

- **Обучить новое поколение** — обучение с нуля в новой папке модели.
- **Дообучить** — новый материал вместе с повтором прежнего опыта и проверкой его сохранения.
- **Возобновить** — продолжение прерванного вычисления с завершённой контрольной точки, с совместимыми данными и параметрами.

Семейства моделей, несовместимые форматы и профили не следует смешивать в одной папке. Старое поколение сохраняй отдельно. Отмена не превращает промежуточную модель в принятую.

### Отдельный эксперимент: выстрелы и подборы

Ниже на странице расположен блок «Выстрелы и подборы предметов». Для него нужны повторно импортированные проекты актуального формата, отдельная подготовка событий, отдельная папка модели и собственный подбор размера пакета. Здесь изучаются наблюдаемые выстрелы и сообщения о подборе, а не доказанно оптимальные игровые решения.

## 5. Работа в фоне и загрузка оборудования

Вычисления, запуск процесса и обработка его сообщений выполняются в фоне. Во время работы можно переключать страницы, смотреть журнал и менять параметры следующего задания. Одновременно запускается одно вычислительное задание: это защищает модели и проекты от конкурирующей записи.

Панель внизу окна обновляется примерно раз в секунду:

| Показатель | Что означает |
| --- | --- |
| CPU | Общая загрузка логических процессоров компьютера. |
| RAM | Занятая и общая физическая память компьютера, GiB. |
| GPU | Загрузка самой занятой аппаратной очереди выбранной карты. |
| Видеопамять | Занятая выделенная память и доступный системе объём выбранной карты. |
| Задание | CPU и резидентная RAM процесса вычислений и активных дочерних процессов. |

Выбор GPU в панели меняет **только показания**; устройство обучения выбирается в параметрах задания. Недоступные значения показаны прочерком. Общая с CPU память GPU указана в подсказке. Объём памяти может отличаться от номинала на коробке, а сумма RAM дочерних процессов может повторно учитывать общие страницы.

### Отмена и выход

Текущее задание отменяется в разделе «Задания». При закрытии окна во время работы появляется вопрос. **Продолжить работу** выбран по умолчанию: вычисление продолжается. **Остановить и выйти** запрашивает штатную остановку и закрывает окно после завершения процесса.

Предыдущая модель и завершённые контрольные точки сохраняются. Незавершённая часть текущего шага может быть потеряна. Во время остановки интерфейс остаётся доступным. Кнопка **Остаться в программе после остановки** отменяет автоматический выход, но не возобновляет уже отменяемое вычисление.

Открытие вопроса само по себе не отменяет задание. При ошибке выполнения окно остаётся открытым с результатом. Принудительное завершение программы средствами операционной системы не является штатной отменой.

## 6. Результаты, библиотека и сохранность данных

В разделе «Задания» доступны прогресс, журнал, краткий результат и путь к папке задания. Полный результат сохраняется в **result.json** при успешном завершении; **events.jsonl** содержит ход работы, **stderr.txt** — диагностический вывод среды.

Сравнивай результаты модели с простыми базовыми вариантами и отдельно по картам, редким событиям и независимым матчам. Общая точность выбора оружия может быть высокой только потому, что игрок долго держал одну пушку. Это не подтверждает качество переключений, контроля или стрельбы.

«Библиотека» собирает офлайн-пакет из проекта и результатов анализа, проверяет его целостность и добавляет в локальную библиотеку. Добавление модели и чата задаётся отдельно. Непрошедшие проверку компоненты не должны выдаваться за пригодные для игры.

**Текущий пакет не устанавливается на игровой сервер.** Проверка целостности означает, что данные читаются без повреждения, а не то, что новая карта уже обучена для матчей.

### Где находятся данные

По умолчанию настройки и рабочие данные находятся здесь:

```text
%LOCALAPPDATA%\QuakeJourney\BotTrainingStudio
```

Настройки: **settings.json**. Основные каталоги: **projects**, **datasets**, **models**, **jobs**, **exports**, **library**. Для изолированных проверок разработчик может задать другой корень через **BTS_HOME**. Если папки проектов и моделей выбраны вручную, они остаются в выбранных местах.

Для восстановления сохраняй проекты, оригинальные BSP и демки, папки моделей с историей и контрольными точками, настройки и нужные экспортированные пакеты. Публикация исходников на GitHub не является резервной копией твоих локальных записей или обученных весов.

## 7. Решение типичных проблем

| Ситуация | Что делать |
| --- | --- |
| Среда не найдена | Проверь полный комплект runtime/worker. При необходимости укажи Python и worker в «Настройки». |
| GPU не найден | Выполни проверку оборудования. Проверь совместимость установленной среды с GPU; для проверки выбери CPU. |
| Не хватает памяти | Уменьши пакет, контекст или профиль и повтори измерение ресурсов. Не удаляй прежнюю модель. |
| RAR не открывается | Установи WinRAR/UnRAR либо предоставь распакованные DM2/MVD2 или ZIP. |
| Проект устарел | Повтори импорт оригинальных записей и подготовку выборки. Используй новую папку для несовместимой модели. |
| Недостаточно независимых матчей | Добавь новые встречи. Не переноси проверочные данные в обучающую часть. |
| Дообучение отклонено | Изучи проверку сохранения прежних карт. Сохрани старое поколение и проверь качество нового материала. |
| Остановка занимает время | Дождись завершения текущей операции и сохранения. Можно остаться в программе; окно не должно блокироваться. |

Если ошибка повторяется, сохрани версию программы, действие, **request.json**, **events.jsonl**, **stderr.txt** и описание входных данных. Перед отправкой проверь личные пути, содержимое чата и приватные записи. Не публикуй ключи и конфиги серверов.
