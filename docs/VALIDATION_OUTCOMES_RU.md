# Обучение исходам эпизодов — 2026-10-07

Продолжение предварительной версии Studio 0.2. Игровой мод, q3t2 и q2duel1
не изменялись. Все результаты ниже — офлайн-наблюдения, не приёмка игры бота.

## Исправления

Анализатор удалял кадры смерти ещё до подготовки последовательностей.
Затем подготовка требовала непрерывного живого участка на всём горизонте.
Оба ограничения исправлены: первый кадр смерти сохранён, смерть завершает
эпизод, короткая история после респавна дополняется явно обозначенными
пустыми кадрами. Пропуск записи не считается выживанием. Посмертные
координаты/новый респавн не используются как цель движения. Неизвестные
цели исключаются из функции потерь и метрик отдельными масками.

Формат v3 добавляет наблюдаемый боезапас текущей пушки, время после
последнего наблюдаемого выстрела и скорость известного противника.
Полный инвентарь и доступность предметов не выдумываются. Возраст наблюдаемого
выстрела сам по себе не является таймером готовности оружия.

Модель предсказывает смерть, потерю суммарно минимум 20 единиц здоровья/брони
и пополнение здоровья/брони в горизонте трёх секунд либо до смерти. Потеря
включает урон себе; это не метка попадания соперника. Первоначальная метка
любого уменьшения здоровья была заменена: обычное убывание мегахелса мало
помогает оценивать опасный размен. Терминальный исход отделён от измерения
количества ресурсов ровно через три секунды.

Смены оружия получают повышенный вес, рассчитанный только по train и
ограниченный 8×. Отдельно измеряются правильность после смены, сохранение
оружия и ложные смены. Высокая общая точность при постоянном копировании
текущей пушки не позволяет пройти проверку. Выбор эпохи учитывает несколько
семейств задач, а не только скорость движения; test не выбирает эпоху.

## Реальные прогоны

Повторно обработаны 41 запись q2duel5 и 14 ztn2dm3. Получено 293 036 строк,
включая 414 терминальных наблюдений; 403 из них принадлежат допустимым
группам перед последующим выбором примеров. Исходные ревизии и модели не
удалены. История — 16 кадров. Подготовлено 6000 train, 6000 validation и
2871 test последовательность. В train — 25 групп, validation — 3, test — 2.
Ограничение replay на карту даёт для совместного обучения 4380/5733/2871
примеров; обе модели используют одинаковые примеры.

Compact и Balanced обучались по 20 эпох на RTX 5090/CUDA. На исходном test:

| Карта | Compact: ошибка скорости | Balanced | Продолжить текущее движение |
|---|---:|---:|---:|
| q2duel5 | 130,53 | 134,50 | 160,12 |
| ztn2dm3 | 136,03 | 142,64 | 167,78 |

Единицы — единицы карты в секунду. Эти цифры нельзя прямо сравнивать с v1:
состав выборки изменился, теперь присутствуют ранее исключённые эпизоды.
Большая модель не дала автоматического улучшения.

Дополнительно проведено пять фиксированных разбиений только исходных
тренировочных групп. В каждом разбиении свои train/validation/test, целые
группы не пересекаются. Исходные validation/test исключены из этого опыта.
Каждый прогон Compact — 20 эпох; не выбирается лучший из пяти результатов.
Ниже средний Brier score; меньше — лучше. Базовый прогноз — постоянная
частота события, рассчитанная по тренировочной части соответствующей карты.

| Прогноз | q2duel5: модель / база | ztn2dm3: модель / база | Улучшение по разбиениям |
|---|---:|---:|---|
| Потеря ≥20 стека | 0,14556 / 0,15498 | 0,14217 / 0,15950 | 5/5 на каждой карте |
| Пополнение ресурсов | 0,19464 / 0,19993 | 0,21840 / 0,22734 | 5/5 на каждой карте |
| Смерть | 0,04319 / 0,04498 | 0,03279 / 0,03354 | 4/5 на каждой карте |

В ztn2dm3 внутренних тестовых разбиениях всего 2–10 положительных примеров
смерти; в исходной тестовой группе — ни одного. Надёжное обобщение прогноза
смерти пока не подтверждено. Отдельные вероятностные прогнозы также не
доказывают, что модель умеет выбирать действие, предотвращающее смерть.

## Дообучение и стиль

Выполнено настоящее последовательное обучение q2duel5 → ztn2dm3, по 20 эпох.
Прежняя модель передаёт прогнозы движения и вероятностей на старых примерах.
Проверяются ограничения +1% по скорости, +3% по смещению, +5% по Brier для
ранее прошедших базовое сравнение исходов. Новый кандидат прошёл проверку.
На прежних q2duel5 validation-примерах ошибка скорости изменилась
134,11 → 132,87, смещения 226,73 → 225,12; Brier смерти 0,03246 → 0,03195,
потери стека 0,12253 → 0,12237, восстановления 0,18827 → 0,18637.
Это сохранение указанных наблюдательных прогнозов, не всей игровой тактики.

Добавлен профиль поведения по дистанции, здоровью, наличию брони, лучу
видимости и относительной высоте противника. Отдельно считаются сближение,
отход, боковое движение, остановка и оружие. Каждая запись имеет равный вес.
Используется только train, при выбранном доноре — проверка нечёткой похожести
ника и отсутствия неоднозначного совпадения с соперником.
В общих профилях q2duel5/ztn2dm3 — 56/25 условий с минимум 30 наблюдениями
из минимум трёх записей. Это не утверждение о трёх независимых игроках или
полном клонировании стиля. Неизвестный противник не становится неподвижной
мишенью, неизвестная геометрия не считается видимостью.

## Проверки и пакет

- 38 автоматических тестов прошли во встроенной CPU-среде; проверяются raw
  death → parquet → последовательность, маски, разрывы, респавны, боезапас,
  отсутствие зависимости от test при вычислении весов и профиля, отмена,
  побитное возобновление CPU-обучения и целостность данных.
- Desktop пересобран; 28 видов RU/EN × light/dark × страницы отрисованы,
  русская страница обучения просмотрена. Новый worker включён в пакет.
- Реальные офлайн-пакеты обеих карт с условным профилем успешно скомпилированы
  и прочитаны валидатором. Они остаются `server_installable=false`.
- Обычные маршруты: 633 узла / 3776 связей q2duel5 и 1101 / 5113 ztn2dm3;
  эти проверки не подтверждают новые целые триксы или динамические платформы.

Локальные подробные результаты: `local/experiments/outcomes-v3`,
`local/experiments/outcomes-v3-group-folds`,
`local/experiments/outcomes-v3-continual`. Исходные записи, веса, профили
реальных людей и кэши в публичный Git не включаются.

## Что ещё не готово

Выбор оружия, точное изменение количества ресурсов и близость к предмету
по-прежнему не прошли свои базовые сравнения. Эти выходы исключаются из
экспортируемой политики. В частности, точность Compact после реальной смены
оружия на test — только 1,1% на q2duel5 и 2,6% на ztn2dm3.

Следующий тактический этап требует меток доступных действий и целей,
подтверждённых подборов/таймингов, состояния доступного оружия и истории
длиннее короткого фрагмента боя. Нужно отдельно квалифицировать полные
маршруты/триксы, рикошеты и выбор действий по их последствиям. Сохранены
ограничения по AMD/Intel и проверке на чистой машине. Загрузчик знаний в
игровом моде и оценка реальной игры остаются согласованным будущим этапом.
