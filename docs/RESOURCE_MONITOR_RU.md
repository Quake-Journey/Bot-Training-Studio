# Мониторинг ресурсов

2026-10-07. Реализован по образцу панели загрузки Mapgen Studio.
Панель закреплена внизу всех страниц и остаётся видимой при прокрутке.
Поддержаны русский/английский интерфейс, светлая/тёмная/системная темы.

## Показания

- CPU: доля занятого времени всех логических процессоров компьютера.
- RAM: занятая / общая физическая память компьютера в GiB.
- GPU: загрузка самой занятой аппаратной очереди выбранной видеокарты.
  Нагрузки процессов на одну очередь суммируются, независимые очереди
  не складываются между собой. Это принцип показаний WDDM, используемых
  Windows, а не доля времени только модели.
- Видеопамять: занятая выделенная память / объём, предоставленный DXGI
  для этой же карты. Объём может отличаться от номинала на коробке и
  свободной памяти Torch. Общая с CPU память GPU показана в подсказке.
- «Задание»: CPU и RAM Python-процесса и его активных дочерних процессов,
  включая декодер. CPU нормирован по всем логическим процессорам.
  RAM — сумма working set; общие страницы могут учитываться повторно.
  Короткий дочерний процесс между опросами может не попасть в показания.

Если карт несколько, выпадающий список выбирает карту **для мониторинга**.
Он не меняет устройство обучения. При первом определении выбирается карта
с наибольшей выделенной памятью; выбранная карта сохраняется при переходах
между страницами. Счётчики и объём памяти связаны по LUID устройства:
показания разных GPU не смешиваются.

С версии 0.3.0-preview.2 список отбирает аппаратные render/compute-устройства по D3DKMT_ADAPTERTYPE. Виртуальные дисплеи, программный рендерер Windows и неизвестные LUID из счётчиков не создают пунктов меню. Одинаковые названия двух настоящих карт не объединяются: они получают номера.

Недоступное значение показано прочерком. Для встроенной GPU без выделенного
объёма нельзя выдумывать процент заполнения VRAM: доступный объём занятой
памяти показывается без знаменателя. Устаревшие показания скрываются через
пять секунд. После завершения задания его показатели очищаются.

## Реализация и ограничения

Один фоновый сборщик на окно, интервал около секунды. UI забирает готовый
снимок без вызова драйвера. PDH English counters не зависят от языка Windows;
DXGI определяет устройства и объём памяти. Нет nvidia-smi, запуска Python
или импорта Torch ради мониторинга. Сборщик освобождает PDH-запрос при
закрытии окна, не блокируя UI ожиданием драйвера.

GPU-интерфейс общий для WDDM-драйверов NVIDIA, AMD и Intel. Аппаратная
проверка проведена на NVIDIA RTX 5090; AMD/Intel и реальные системы с двумя
GPU пока не проверены. Отсутствие счётчиков не означает нулевую загрузку.
Текущий системный монитор рассчитан на Windows. Это не подтверждение
готовности обучающей модели или совместимости runtime с любым GPU.

## Проверки

- Сборка .NET без ошибок и предупреждений.
- 16 проверок мониторинга: независимость двух GPU, агрегация процессов и
  очередей, неизвестные значения, реальные CPU/RAM, очистка завершённого
  задания, CUDA-калибровки, длительное обновление весов и остановка сборщика.
- При CPU-нагрузке двух потоков: около 6% всей машины, около 0,12 GiB RAM
  тестового процесса. При длительном CUDA-вычислении: GPU около 38–50%,
  выделенная память карты выросла примерно с 4,1 до 5,1 GiB, RAM процесса
  составила около 1,25 GiB. Это замер конкретного теста, не требования модели.
- 40 отрисовок RU/EN × светлая/тёмная тема: все страницы, нижняя часть
  обучения, неизвестные показания и высокая нагрузка в окне 980 × 700.
  Визуально проверены показания и границы полосок.

Mapgen Studio и игровой мод не изменены. Обучающие датасеты, модели,
приватные записи и конфиги не затронуты.
