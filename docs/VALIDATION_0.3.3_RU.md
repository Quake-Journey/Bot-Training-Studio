# Проверка 0.3.0-preview.3 — 7 октября 2026

Исправлено развёртывание Python в пользовательской студии. Полный пакет содержит
официальный архив CPython 3.13.16 x64 в `worker/runtime/` с SHA256 из lock-файла;
это расположение совместимо с опубликованным обновлятором предыдущей версии.
Установка извлекает
его локально в отдельное поколение внутри каталога данных Studio. Системные
установки Python и PATH не изменяются. Библиотеки остаются в папке приложения.

Проверены две рабочие конфигурации: комплектный Python 3.13 с комплектными
библиотеками и готовая среда Python 3.12 с собственными библиотеками. Во втором
случае Studio не добавляет несовместимые cp313-библиотеки и не отключает
site-packages рабочего окружения. Выбор источника библиотек сохраняется.

## Пройденные проверки

- Runtime: 28 проверок, включая повреждённый локальный архив, PE/x64,
  контрольную сумму, границы распаковки и запуск настоящего worker в Python 3.12.
- Setup UI: 28 проверок без Python в PATH. Установка из стартового диалога,
  навигация, отмена, повторная попытка, активация, сохранение настроек,
  повторное использование среды и реальный forward/backward/optimizer step
  модели на NVIDIA CUDA. На проверочном компьютере — RTX 5090.
- Updates UI: 30 проверок. Модальная проверка, обе локализации, действия
  установки/настроек, отсутствие наложения changelog, постоянный выбор CPU/GPU.
- Update transaction: 31 проверка. Архив Python принадлежит пакету приложения;
  обновление и откат сохраняют пользовательские файлы и комплектные библиотеки.
- Выход во время установки: 7 проверок; прежняя среда сохраняется, временное
  поколение очищается, окно закрывается после остановки.
- Жизненный цикл заданий: 18 проверок, включая отзывчивость интерфейса,
  кооперативную остановку и отсутствие оставшегося worker после закрытия.
- Руководства RU/EN: генерация и проверки свежести DOCX, 5 проверок структуры;
  открытие только для чтения и визуальная проверка страниц, отрендеренных Word.

Локальные свидетельства: `artifacts/python-bundle-preview3/` и
`artifacts/guides-0.3.0-preview.3-final/`. Они не публикуются с исходниками.
Контрольные суммы пакета и вложений выпуска публикуются отдельно.

Это проверка установки и вычислений. Она не означает завершения полноценного
тактического обучения, поддержки AMD/Intel GPU или экспорта в игровой мод.
