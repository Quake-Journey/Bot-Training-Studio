# Bot Training Studio

## 0.3.0-preview.4 — 2026-10-07

- Окно истории показывает все версии со скроллингом, в том числе при первом запуске обновлённой студии.
- Комплектные экспериментальные модели Compact и Balanced для q2duel5 и ztn2dm3 находятся в Models рядом с программой. Пользовательское дообучение хранится отдельно и не перезаписывается обновлениями.
- Добавлен запуск обучения от заводской основы: фиксируется её версия, сохраняются отдельные пользовательские дополнения весов. Экспорт читает основу и дополнение; несовместимые данные не смешиваются.
- Настройки, поля, кнопки и индикаторы получили поясняющие подсказки на языке интерфейса. Обновлены руководства RU/EN и требования к будущему локальному помощнику для указаний обычным языком.

## 0.3.0-preview.3 — 2026-10-07

- Python 3.13 x64 включён в полный пакет. При отсутствии подходящей среды стартовое окно предлагает установить его из комплекта без интернета и прав администратора.
- Готовые окружения Python 3.12 и новее с необходимыми библиотеками проходят проверку вычислений и могут использоваться напрямую; несовместимые двоичные библиотеки комплекта в них не подмешиваются.
- Обновлены установка, проверка целостности, встроенное обновление и руководства RU/EN для комплектного Python.

## 0.3.0-preview.2 — 2026-10-07

- Стартовая проверка Python и библиотек перенесена в отдельное модальное окно; установщик больше не появляется и не исчезает на главной странице.
- Список GPU показывает физические видеокарты: исключены виртуальные дисплеи, программный рендерер Windows и безымянные записи счётчиков. Две настоящие карты одной модели остаются отдельными устройствами.
- После запуска новой распакованной копии используется её комплектный модуль обучения, а не модуль из прежней папки.
- Обновлены руководства RU/EN. Проверка среды не перекрывается журналом изменений и не блокирует обработку интерфейса.

## 0.3.0-preview.1 — 2026-10-07

- Постоянный выбор CPU/GPU на главной странице, в обучении и настройках: проверка Python больше не скрывает выбор вычислений.
- Номер версии в заголовке и интерфейсе; список изменений при первом запуске новой версии и кнопка «Что нового».
- Автоматическая проверка GitHub Releases и ручная кнопка обновления. Установка обновления доступна после завершения заданий, с проверкой файлов и восстановлением прежней сборки при ошибке.
- Библиотеки программы и модели входят в комплект; используется совместимый установленный Python или предлагается установка только Python.
- Иконка приложения и обновлённые руководства на русском и английском. Это предварительная исследовательская версия; полноценная тактика и экспорт в игровой мод ещё не готовы.

## 0.2.0 — 2026-10-07

- Исходная предварительная студия: импорт карт и записей, экспериментальное обучение, профили памяти, RU/EN интерфейс и мониторинг ресурсов.
