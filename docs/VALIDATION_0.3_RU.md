# Проверка интерфейса и обновления 0.3.0-preview.1

Дата: 2026-10-07. Windows x64, RTX 5090, комплектные библиотеки CPU/CUDA,
совместимый Python 3.13. Изменений игрового модуля нет.

Причина исчезновения старого списка: он принадлежал панели установки среды,
скрывающейся после успешного обнаружения Python. Выбор вычислений выделен
в постоянный блок на главной странице и в настройках; страницы обучения
используют тот же сохранённый параметр. Нижний выбор GPU относится к мониторингу.

Проверено:

- 31 проверка обновлятора: версия/канал, целостность архивов, повторное использование
  библиотек, multipart-загрузка, отмена, неудача замены с восстановлением файлов,
  сохранение пользовательских данных, ошибки сети и недопустимые пути.
- 16 проверок настоящего интерфейса: CPU/GPU до и после реальной проверки Python,
  сохранение выбора, отзывчивость, первый запуск/повторный запуск/ручная история,
  запрет установки во время задания, отмена, RU/EN. Окна сняты вне видимой области.
- 24 проверки установки среды и иконки; 18 проверок работы и выхода во время
  фонового задания, включая поток сообщений, подтверждение выхода и штатную отмену.
- Отдельный процесс обновлятора с настоящим EXE: ожидание исходного процесса,
  замена файлов по проверенному списку, путь с пробелами, сохранение пользовательских
  моделей и настроек. Автоматический видимый запуск подавлен только в этой проверке.
- Оба DOCX актуальны; Microsoft Word открыл их только для чтения и отрисовал
  по 9 страниц. Изменённые страницы просмотрены, исходные DOCX не изменились.

Контрольные тесты не подтверждают качество тактической модели. Полная тактика,
игровой экспорт, AMD/Intel GPU и проверка на физически чистой машине остаются
отдельными незакрытыми задачами. Текущий выпуск — исследовательский preview.
